# গুগল শীট লাইভ মিরর — সেটআপ

ডাটাবেসে নতুন কিছু ঢুকলে (অর্ডার, কাস্টমার, রিচার্জ, ডিপোজিট, খরচ — সব) কয়েক
সেকেন্ডের মধ্যেই সেটা একটা গুগল শীটে চলে যাবে। কিছু চাপতে হবে না।

একবারের সেটআপ, সময় লাগবে ১০ মিনিট, খরচ নেই। ধাপগুলো ক্রমে করুন।

---

## ১. শীট বানান

1. [sheets.new](https://sheets.new) খুলুন — নতুন একটা খালি শীট তৈরি হবে।
2. নাম দিন, যেমন **FoodBox ডাটাবেস**।
3. ঠিকানার লম্বা অংশটা কপি করে রাখুন — **এটাই `GOOGLE_SHEETS_ID`**:

```
https://docs.google.com/spreadsheets/d/1aBcD...xYz/edit
                                      └──────┬──────┘
                                        এই অংশটা
```

ট্যাব (কাস্টমার, অর্ডার, …) নিজে বানাতে হবে না — প্রথম সিঙ্কেই সব তৈরি হয়ে যাবে।

## ২. গুগল ক্লাউডে প্রজেক্ট আর Sheets API

1. [console.cloud.google.com](https://console.cloud.google.com) — যে গুগল
   অ্যাকাউন্টে শীট বানিয়েছেন, সেটাতেই লগইন করুন।
2. উপরে বাঁদিকের প্রজেক্ট ড্রপডাউন → **New Project** → নাম `foodbox` → **Create**।
3. নতুন প্রজেক্টটা সিলেক্ট করা আছে কি না দেখে নিন (উপরে নাম দেখাবে)।
4. সার্চ বারে **Google Sheets API** লিখুন → প্রথম রেজাল্ট → **Enable**।

এই ধাপটা বাদ গেলে পরে `403 ... Google Sheets API has not been used` আসবে।

## ৩. সার্ভিস অ্যাকাউন্ট আর key

সার্ভিস অ্যাকাউন্ট হলো "রোবট ইউজার" — আপনার সার্ভার এই পরিচয়ে শীটে লেখে, কাউকে
লগইন করতে হয় না।

1. বাঁ মেনু → **APIs & Services → Credentials**
2. উপরে **+ Create Credentials → Service account**
3. নাম: `foodbox-sync` → **Create and continue** → রোল না দিয়েই **Done**
   (শীটের পারমিশন পরের ধাপে শীট থেকেই দেওয়া হবে, এখানে লাগবে না)
4. তালিকা থেকে `foodbox-sync` এ ক্লিক করুন → **Keys** ট্যাব →
   **Add key → Create new key → JSON → Create**
5. একটা `.json` ফাইল নামবে। **এটাই চাবি — কাউকে পাঠাবেন না, গিটে রাখবেন না।**

ফাইলটা খুললে ভেতরে এরকম দুটো লাইন আছে, এগুলোই লাগবে:

```json
{
  "client_email": "foodbox-sync@foodbox-xxxxx.iam.gserviceaccount.com",
  "private_key": "-----BEGIN PRIVATE KEY-----\nMIIEvQ...\n-----END PRIVATE KEY-----\n"
}
```

## ৪. শীটটা রোবটকে দিন ⚠️

**এই ধাপটা সবাই ভুলে যায়** — বাদ গেলে `403` আসবে।

1. শীট খুলুন → উপরে ডানে **Share**
2. উপরের `client_email` টা পেস্ট করুন
3. পারমিশন **Editor** দিন
4. "Notify people" টিক তুলে দিন → **Share**

## ৫. environment variable বসান

### লোকাল (`.env.local`)

```bash
GOOGLE_SHEETS_ID=1aBcD...xYz
GOOGLE_SERVICE_ACCOUNT_EMAIL=foodbox-sync@foodbox-xxxxx.iam.gserviceaccount.com
GOOGLE_SERVICE_ACCOUNT_KEY="-----BEGIN PRIVATE KEY-----\nMIIEvQ...\n-----END PRIVATE KEY-----\n"
```

`private_key` এর ভ্যালুটা JSON থেকে **হুবহু** কপি করুন — `\n` গুলো যেমন আছে তেমনই
থাকবে, কোড নিজে ঠিক করে নেয়। ডাবল কোটেশন রাখলেও চলবে।

### লাইভ (Vercel)

**Settings → Environment Variables** এ একই তিনটা, **Production** টিক দিয়ে।
`GOOGLE_SERVICE_ACCOUNT_KEY` এর ঘরে JSON-এর ভ্যালুটা পেস্ট করুন (কোটেশন ছাড়া,
`\n` সহ)।

এরপর **Redeploy** — শুধু সেভ করলে পুরোনো বিল্ড পুরোনো env নিয়েই চলতে থাকে।

ঐচ্ছিক: `CRON_SECRET` এ একটা লম্বা random স্ট্রিং দিন। এটা থাকলে প্রতিদিন রাত
২টায় (বাংলাদেশ সময়) একটা নিরাপত্তা-সিঙ্ক চলবে — ডাটাবেসে অ্যাপের বাইরে থেকে কিছু
বদলালে সেটাও ধরা পড়বে। `vercel.json` এ শিডিউলটা আছে।

## ৬. চালু হয়েছে কি না দেখুন

1. `/api/health` খুলুন — `"GOOGLE_SHEETS": true` দেখাবে।
2. অ্যাডমিন প্যানেল → **সেটিংস** → **গুগল শীট (লাইভ)** কার্ডে **চালু** লেখা থাকবে।
3. **এখনই সিঙ্ক করুন** চাপুন → শীটে ১৪টা ট্যাব তৈরি হয়ে ডেটা বসে যাবে।
4. এবার সাইট থেকে একটা টেস্ট অর্ডার দিন → ২-৩ সেকেন্ড পরে শীট রিফ্রেশ করুন, নতুন
   সারিটা **অর্ডার** ট্যাবে থাকবে।

## কিছু ভুল হলে

| যা দেখবেন | কারণ ও সমাধান |
|---|---|
| `403 — share the sheet with …` | ধাপ ৪ বাদ পড়েছে। ঐ ইমেইলটাকে Editor করে শেয়ার করুন। |
| `403 ... Sheets API has not been used` | ধাপ ২.৪ বাদ পড়েছে — Google Sheets API enable করুন। |
| `404 — GOOGLE_SHEETS_ID does not match` | আইডি ভুল। URL-এর `/d/` আর `/edit` এর মাঝের অংশটাই আইডি। |
| `Google refused the service account` | key ঠিকমতো কপি হয়নি। `-----BEGIN` / `-----END` লাইন আর `\n` গুলো থাকতে হবে। |
| শীট খালি, কোনো এরর নেই | `/api/health` দেখুন — `GOOGLE_SHEETS: false` মানে env বসেনি বা redeploy হয়নি। |

সিঙ্ক কখনোই অ্যাপ ভাঙে না — গুগল বন্ধ থাকলেও অর্ডার আগের মতোই হবে, শুধু সার্ভার
লগে `[sheets] sync failed` থাকবে আর পরের লেখায় আবার মিলে যাবে।

## শীটে কী কোথায়

| ট্যাব | কী আছে |
|---|---|
| **সারসংক্ষেপ** | লাভ–লোকসান, অর্ডারের অবস্থা, কাস্টমার ও ওয়ালেটের হিসাব — প্রতিটা সংখ্যার পাশে ব্যাখ্যা। অ্যাডমিন প্যানেলের হিসাবের সাথে হুবহু মেলে। |
| **কাস্টমার** | এক কাস্টমার = এক সারি। ফোন, ঠিকানা, সাবস্ক্রিপশন, ওয়ালেটের তিন হিসাব, বক্স ডিপোজিট, কয়টা অর্ডার, কত খরচ করেছে, শেষ অর্ডার কবে। |
| বাকি ট্যাব | অর্ডার, সাবস্ক্রিপশন, রিচার্জ, ডিপোজিট, খরচ, মেনু, প্যাকেজ, জোন, অ্যাডমিন, সেটিংস। |

ডাটাবেস আইডি গুলো প্রতিটা ট্যাবের **শেষ** কলামে — দরকার হলে আছে, কিন্তু চোখের
সামনে নেই। স্টেটাস কলামে রঙ: সবুজ = হয়ে গেছে, হলুদ = অপেক্ষায়, লাল = বাতিল।
প্রথম সারি আর প্রথম কলাম আটকানো, উপরে ফিল্টার আছে — তাই বড় টেবিলেও হারিয়ে
যাবেন না।

## মনে রাখার মতো

- **শীটে নিজে ডেটা এডিট করবেন না।** প্রতিটা সিঙ্ক ট্যাবটা পুরো নতুন করে লেখে, তাই
  হাতে লেখা কিছু মুছে যাবে। হিসাব করতে চাইলে **নতুন একটা ট্যাব** বানিয়ে সেখান থেকে
  `=কাস্টমার!H2` এভাবে রেফার করুন — নিজের বানানো ট্যাব কোড ছোঁয় না।
- শীটে কাস্টমারের ফোন নাম্বার আর ঠিকানা থাকে। শেয়ার লিংক **"anyone with the
  link"** করবেন না।
- নিরাপত্তার জন্য পাসওয়ার্ড শীটে যায় না।
- শীট অনলাইন কপি; মাসে একবার `node scripts/backup-db.mjs` চালিয়ে একটা অফলাইন
  কপিও রাখুন — ঐটাই হুবহু রিস্টোর করা যায়।
